# LuaS30 Engine 1.6.2 — Font Icon UI

- Removed emoji/pictogram-style control text from the Studio.
- Added `studio/app/ui/icons.py`.
- Uses Windows system font icons: Segoe Fluent Icons / Segoe MDL2 Assets.
- No font files are bundled.
- Activity Bar, menus, top command bar, Explorer toolbar, Find/Replace and major
  view actions now use the centralized font-icon layer.
- Status bar no longer uses Unicode symbol characters for readiness/problems.
- Added the no-emoji/font-icon rule to `SKILL.md` and `PROMPT.md`.
- Updated About/Credits and Studio documentation.
