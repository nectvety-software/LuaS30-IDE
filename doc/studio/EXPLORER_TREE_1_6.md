# Explorer Tree v1.6

The VS Code-style Explorer is now a real filesystem tree:

- folders first;
- expandable/collapsible hierarchy;
- New File / New Folder toolbar;
- Rename / Delete;
- Open;
- Copy Path / Copy Relative Path;
- Reveal in File Explorer;
- Refresh;
- optional display of `build`, `release`, `dist`;
- hides `.git`, `.venv`, `__pycache__`, `.idea`, `.pytest_cache` by default.

It stays rooted at the currently opened project and double-clicking a file
opens the existing tab editor.
