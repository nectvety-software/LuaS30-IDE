# Doodle Quest — LuaS30 game template

A lightweight 240×320 game template with procedural notebook/doodle graphics and a complete keypad UI.

## Included screens

- Splash
- Main menu
- How To Play
- Settings
- About
- Gameplay + HUD
- Win / Game Over state

## Controls

- 2 / 8: up / down
- 4 / 6: left / right
- 5 or #: confirm
- 0 / Back / Soft Left: back

## Target

- Nokia S30+ / MediaTek MRE
- MTK6260
- 240×320
- 1024 KB baseline heap
- 15 FPS
- profile: `nokia225-rm1011`

The graphics are drawn with rectangles, frames and text, so the template works without loading large bitmap assets and is suitable as a low-RAM starter project.
