# CatBoxMRE v0.5.0

## Comic panel boss cutscenes

Each boss cutscene now uses a more complete comic layout:
- top title bar
- three framed comic panels
- short message bubbles
- action badge
- bottom skip bar

All cutscenes remain procedural and lightweight for Nokia 225.

## Quest chains

Each of the four main NPC quests now has three stages.
Talk to the quest giver after each milestone to receive the next objective.

## Shop and wallet

Wallet coins are earned when clearing levels:
- +1 per level coin collected
- +2 per star earned at level clear

Main Menu -> Shop.

### Permanent items
- Heart Charm: +1 starting life (up to +2 total)
- Coin Magnet: larger coin pickup range
- Guard Bell: one starting shield per level

### Shop skins
- Rose
- Emerald

## Controls

- Main Menu -> Shop
- UP / DOWN: select entry
- 5 / OK: buy
- Right softkey: back
