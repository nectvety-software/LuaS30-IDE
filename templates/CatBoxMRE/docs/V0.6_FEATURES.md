# CatBoxMRE v0.6.0

## New UI screens

### Quest Log
Main Menu -> Quest Log

- Lists all four quest chains
- Shows current state: Not Started / Step X/Y / Complete
- Shows quest giver, reward and current objective text
- Optimized for 240x320 portrait layout

### Shop Tabs
Main Menu -> Shop

- Left/Right (4/6) switches between:
  - Items
  - Skins
- Up/Down selects entry
- OK buys current entry

Item icons:
- Heart Charm
- Coin Magnet
- Guard Bell

Skin tab:
- Shows Rose and Emerald shop skins with simple cat preview icons

## Boss cutscenes

All four bosses now use comic-panel dialogue scenes:
- Intro
- Phase 2 transition
- Victory

Each panel contains:
- cat dialogue
- boss reply
- lightweight comic framing
- skip prompt

The feature remains procedural/vector-based for Nokia 225 performance.
