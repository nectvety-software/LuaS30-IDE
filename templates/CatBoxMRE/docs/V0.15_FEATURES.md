# CatBoxMRE v0.15.0 — Low-Memory Boss Upgrade

## Boss HUD
- Small skill icon is shown beside the HP bar.
- Warning indicator appears shortly before a special attack.

## Unique boss specials
The system uses a fixed pool of only 4 hazard objects. No new tables are allocated per frame.

- Moss King: moving vine wave.
- Picnic Brute: fast ram shockwave.
- Phantom Keeper: aimed ghost orb.
- Sky Warden: warning column followed by lightning.

At low HP the existing boss movement/attack timings also accelerate.

## Comic cut-in
To avoid restoring the heavy v0.14 comic subsystem, v0.15 uses a lightweight in-game comic cut-in:
- ROAR! / BOOM! / WHOO! / ZAP!
- screen-panel shake
- panel-break marks
- slash accents

## OOM protection
All memory declarations are synchronized to 512 KB:
- `project.json`
- `.luas30/mre_sdk.json`
- `conf.lua`

The previous low-memory build still had `conf.lua = 1024 KB`, which could cause an external builder to request too much heap depending on which metadata source it used.

Production bundle is compacted and checked by `tools/memory_guard.py`.
