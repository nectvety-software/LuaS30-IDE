# CatBoxMRE v0.3.0 — World Map, Boss, NPC, Secret Areas

## Controls

- D-pad left/right: move / choose map node
- D-pad up: jump
- `5` / OK: jump, talk to nearby NPC, select World Map node
- D-pad down / `8`: enter or leave a glowing secret portal
- Left softkey: pause
- Right softkey / back: return / close dialogue
- `0`: restart current level
- `#`: debug overlay
- `*`: debug page
- `9`: force full GC

## World Map

The 26 levels remain split across four worlds. The map now shows:

- world completion percent;
- star progress;
- boss crowns;
- locked/unlocked nodes;
- hidden-secret badges;
- animated player marker;
- selected-stage detail card.

Boss stages are 7, 13, 19 and 26.

## Bosses

- World 1: Moss King — patrol + leap.
- World 2: Picnic Brute — charge attack.
- World 3: Phantom Keeper — hover + dive.
- World 4: Sky Warden — aerial dash.

Bosses are defeated by stomping their head. The goal door stays locked until the boss is defeated.

## NPC dialogue

NPCs appear in all four worlds. Stand near one and press OK/5. Each NPC provides short gameplay hints suitable for the 240x320 screen.

## Secret areas

Secret portals exist in levels 3, 10, 17 and 24. Press DOWN/8 near the glowing portal to enter. Each secret room contains bonus coins and one persistent secret gem. Secret discovery is saved and displayed on the World Map.

## Memory policy

The update keeps the fixed pools from previous releases:

- 20 enemies
- 8 push boxes
- 24 FX

Boss/NPC/secret state uses fixed or stage-static tables; no unbounded per-frame allocation path was added.
