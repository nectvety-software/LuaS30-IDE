# CatBoxMRE v0.12.0

## 1. Boss portraits by health state
Each boss portrait now changes visual details based on health state:
- healthy
- wounded
- critical

Examples:
- Moss King: leaf / bark damage
- Picnic Brute: scratches / heavier damage
- Phantom Keeper: faded ghost cracks
- Sky Warden: brighter broken-wing / spark damage

## 2. Boss-specific battle SFX
Boss combat now has identity through procedural tone sets:
- engage warning
- attack
- land / impact when relevant
- hit reaction
- phase 2 trigger
- defeat

Each boss uses different tone combinations.

## 3. Roar panel FX in cutscenes
When a boss uses a roar-type expression in comic cutscenes:
- the panel can shake
- highlight flashes appear
- the moment feels more dramatic
