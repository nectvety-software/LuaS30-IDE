# CatBoxMRE v0.7.0

## Shop
- Separate tabs for Items and Skins
- Larger preview area for the selected shop entry
- Bigger visual presentation for upgrade items and skins

## Quest Log
- Each quest has its own icon
- Detailed bottom panel shows:
  - quest giver
  - step info
  - reward skin preview
  - current objective text

## Comic Boss Cutscenes
- Each speech panel now includes:
  - cat portrait
  - boss portrait
  - cat dialogue
  - boss reply
- Still procedural and lightweight for Nokia 225 / 240x320

## Compatibility
- Target: Nokia 225 RM-1011
- Screen: 240x320
- Runtime: LuaS30 / MRE VXP
