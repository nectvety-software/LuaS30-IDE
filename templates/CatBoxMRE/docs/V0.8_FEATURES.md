# CatBoxMRE v0.8.0

## 1. Expressive portraits
Boss comic cutscenes now use more detailed portrait frames:
- cat expressions: calm, surprise, angry, happy
- boss expressions vary by intro / phase 2 / victory

## 2. Shop buy animation
When buying an item or skin:
- preview panels flash
- sparkle accents appear
- success toast is styled differently

## 3. Unlock popup
Quest reward completion and shop skin purchases now show a dedicated centered unlock popup:
- title bar
- skin preview
- reward text
- celebratory sparkles

## Compatibility
- Nokia 225 RM-1011
- 240x320 portrait
- LuaS30 / MRE VXP
