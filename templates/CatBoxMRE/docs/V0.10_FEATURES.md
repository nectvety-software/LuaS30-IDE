# CatBoxMRE v0.10.0

## Reward popup actions
Unlock popups now have two explicit actions:

- EQUIP
- CLOSE

Controls:
- 4 / 6: switch action
- 5 / OK: confirm
- Right softkey / Back: close

If Equip is selected, the unlocked skin becomes the active skin immediately and is saved.

## Cutscene panel transition SFX
Each comic-panel appearance now triggers its own short tone.

Intro, Phase 2 and Victory use different tone ranges so the three cutscene types feel distinct without using large audio assets.

## Multi-frame boss portraits
Each boss portrait now uses four lightweight procedural frames:

- Moss King: leaf/crown sway
- Picnic Brute: horn shake and snort
- Phantom Keeper: floating/flicker motion
- Sky Warden: wing flap and electric pulse

Blinking and expression logic remain active on top of these frames.

## Compatibility
- Nokia 225 RM-1011
- MTK6260
- 240x320
- LuaS30 / MRE VXP
