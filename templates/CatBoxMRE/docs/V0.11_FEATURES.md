# CatBoxMRE v0.11.0

## More portrait expressions
### Cat
- calm
- happy
- smile
- grin
- surprise
- angry
- shout
- sad

### Bosses
Each boss portrait now supports more expressions and uses them across Intro / Phase 2 / Victory panels:
- calm
- angry
- smirk
- roar
- tired
- sad

## Boss-specific cutscene SFX
Each boss now has different transition tones for the 3 comic panels:

- Moss King: softer organic tones
- Picnic Brute: heavier aggressive tones
- Phantom Keeper: ghostly higher overlay tones
- Sky Warden: bright electric tones

Some bosses also layer a short accent beep for extra identity.
