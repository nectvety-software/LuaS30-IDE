# Reference video analysis

Observed visual/gameplay motifs used as inspiration:
- side-scrolling 2D platform stages
- black cat player character
- bright blue sky, green hills, checker-pattern ground
- vertical and horizontal platforms
- collectible token/coin rows
- keys and an end-of-stage door/box
- spikes, descending crusher/arrow traps
- spring/bounce pads and moving platforms
- crawling ground enemies and floating ghost-like enemies

The implementation uses original procedural/atlas art and does not copy the reference game's exact assets.
