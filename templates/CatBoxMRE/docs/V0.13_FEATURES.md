# CatBoxMRE v0.13.0

## 1. Boss portrait changes in gameplay UI
The boss HUD now includes a small portrait beside the HP bar.
It changes based on current boss HP:

- healthy
- wounded
- critical

Phase 2 is also indicated on the portrait.

## 2. Boss-specific combat VFX
Each boss now has lightweight procedural VFX during combat:

- Moss King: leaf bursts and nature particles
- Picnic Brute: impact bursts / slam style particles
- Phantom Keeper: ghost wisps
- Sky Warden: electric zap particles

These effects are triggered on:
- warning / engage
- attack
- hit
- phase 2
- defeat
- landing / impact when relevant

## 3. Comic SFX text in cutscenes
Boss cutscenes now display comic-style text on strong moments:
- ROAR!
- BOOM!
- ZAP!
- WHOO!
- THUMP!

Combined with shake/flash from the previous version, cutscenes feel more like comic panels.
